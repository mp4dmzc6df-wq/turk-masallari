Giriş

Proje Özeti

Bu projede geleneksel Türk masallarından seçilen 8 farklı masal, modern web teknolojileri kullanılarak tek bir HTML dosyası içerisinde interaktif bir platformda derlenmiştir. Projenin temel amacı, kültürel mirasımız olan masalları dijital ortama taşımak ve kullanıcıların anlık arama (filtreleme) fonksiyonu sayesinde istedikleri masala hızlı ve pratik bir şekilde ulaşmasını sağlamaktır. Tüm sayfa tasarımı ve işlevselliği, harici dosya karmaşasından kaçınılarak tek dosya mimarisiyle hayata geçirilmiştir.

Masalların Seçimi

Derleme çalışmasında Türk halk edebiyatının zenginliğini temsil eden, hem Keloğlan motiflerini hem de efsanevi ögeleri barındıran 8 masal özenle seçilmiştir. Seçilen masallar ve tür özellikleri aşağıdaki tabloda verilmiştir:

No Masal Tür Seçilme nedeni
1 Keloğlan ve Sihirli Tas Halk Masalı Keloğlan’ın zekasını ve mizahi yönünü yansıtması.
2 Zümrüdü Anka Kuşu Efsanevi Masal Mitolojik unsurlar barındırması ve popüler olması.
3 Şahmeran Efsanevi / Mitolojik Anadolu kültürünün en önemli efsanelerinden biri olması.
4 Keloğlan ile Dev Halk Masalı Geleneksel dev motifini ve kurnazlık temasını içermesi.
5 Altın Elma Sihirli Masal Klasik Türk masal yapısını ve macera öğelerini barındırması.
6 Padişahın Kızı ve Derviş Halk / Dini motifli Sabır ve derviş hikmetlerini konu alması.
7 Sihirli Lamba Masal / Macera Anadolu masal geleneğindeki dilek ve sihir temasını işlemesi.
8 Uçan Halı Fantastik Masal Masallardaki fantastik seyahat ögesini temsil etmesi.

Tasarım Kararları

Konuya Uygunluk

Arayüz tasarımında masalsı, sıcak ve nostaljik bir atmosfer yaratmak hedeflenmiştir. Bu doğrultuda kahverengi ve krem tonları bir arada kullanılarak geleneksel dokunun ekrana yansıması sağlanmıştır.

Okunabilirlik, Gezinme ve Duyarlı Tasarım

  • Okunabilirlik: Metin satır uzunlukları optimize edilmiş, uygun font boyutları ve yüksek kontrastlı renkler tercih edilmiştir.

  • Gezinme: Sayfanın en üstünde konumlandırılan anlık arama çubuğu sayesinde kullanıcılar istedikleri masala saniyeler içinde erişebilmektedir.

  • Duyarlı tasarım: CSS Grid yapısı (grid-template-columns: repeat(auto-fit, minmax(280px, 1fr))) ile mobil cihazlarda ve masaüstünde esnek bir yerleşim sağlanmıştır.

  • Tutarlılık: Kart (card) tabanlı yerleşim mimarisi kullanılarak her bir masal için bütüncül bir görsel hiyerarşi kurulmuştur.

Gerçekleştirme

Projede harici CSS veya JS dosyası kullanılmamış, tüm kodlar tek bir index.html dosyası içerisinde yapılandırılmıştır.

HTML Yapısı

Uygulama; başlık alanı (<header>), arama motoru kontrol paneli ve masal kartlarının dinamik olarak konumlandığı grid kapsayıcısından (<div class="grid">) meydana gelmektedir.

İçsel CSS

Stil tanımlamaları sayfanın başındaki <style> bloğunda yer alır. CSS Değişkenleri (:root) ile renk yönetimi merkezi hale getirilmiştir.

:root {
    --primary-color: #5c2c16;
    --secondary-color: #f4e8d8;
    --accent-color: #d97706;
    --text-color: #2b2b2b;
}
.grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
    gap: 20px;
    max-width: 1200px;
    margin: 0 auto;
}

İçsel JavaScript

JavaScript tarafında, arama input alanına girilen her karakteri anlık dinleyen (onkeyup) bir fonksiyon çalışır. Bu fonksiyon kartların veri etiketlerini kontrol ederek eşleşmeyenleri gizler (hidden), eşleşenleri ekranda tutar.

function filterMasallar() {
    let input = document.getElementById('searchInput').value.toLowerCase();
    let cards = document.getElementsByClassName('card');

    for (let i = 0; i < cards.length; i++) {
        let title = cards[i].getAttribute('data-title');
        if (title.includes(input)) {
            cards[i].classList.remove('hidden');
        } else {
            cards[i].classList.add('hidden');
        }
    }
}
